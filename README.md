## 🎯 Overview

This repository contains the **Sumit Panchal - Senior Quality Analyst & QA Engineer portfolio**. It presents professional QA experience, testing practices, selected QA projects, technical skills, and contact information through a dark, cinematic web experience.

The portfolio communicates a practical quality-assurance mindset: understanding requirements, validating complete user journeys, exploring edge cases, reporting defects clearly, verifying fixes, and supporting stable releases.

## ⚙️ Getting Started

### Prerequisites

- **Node.js** - Use a supported Node.js release compatible with the installed Vite version.
- **npm** - Included with Node.js.
- **Git** - Required to clone and publish the repository.

### 1. Clone the repository

```bash
git clone https://github.com/lifeofthecoders/Sumit-Panchal-QA-Cinematic-Portfolio.git
cd Sumit-Panchal-QA-Cinematic-Portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open the local development URL:

```text
http://localhost:5173/
```

### 4. Build the production version

```bash
npm run build
```

The production-ready static website is generated in the `dist/` directory.

### 5. Preview the production build

```bash
npm run preview
```

### Available Scripts

| Command | Purpose |
|---|---|
| `npm run dev` | Start the Vite development server |
| `npm run build` | Run TypeScript project builds and create the Vite production bundle |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run Oxlint |
| `npm run deploy` | Build the project and publish `dist/` using `gh-pages` |

## 🚀 Deployment

The project is configured as a static Vite application and uses the repository subpath as its production base path:

```text
/Sumit-Panchal-QA-Cinematic-Portfolio/
```

### GitHub Pages

1. Push the latest source code to the repository's `main` branch.
2. Confirm that GitHub Pages is enabled for the repository and configured to use **GitHub Actions**.
3. The workflow installs dependencies, runs `npm run build`, and publishes the generated `dist/` directory.
4. Review the Actions run and confirm that the deployment completes successfully.

**Live portfolio:**  
https://lifeofthecoders.github.io/Sumit-Panchal-QA-Cinematic-Portfolio/

### Vercel

The project can also be deployed to Vercel:

1. Import the GitHub repository into Vercel.
2. Select the Vite framework preset.
3. Set the build command to `npm run build`.
4. Set the output directory to `dist`.
5. For a root-domain Vercel deployment, review the Vite `base` setting because the current configuration targets the GitHub Pages repository subpath.
