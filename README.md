## 👋 About

Hi, I'm **Sumit Panchal**, a Quality Analyst focused on delivering reliable, usable, and high-quality digital products.

This cinematic portfolio presents my professional QA journey through an interactive and visually immersive experience.

Rather than simply listing testing skills, the portfolio focuses on how I approach software quality - from understanding requirements and user journeys to identifying defects, validating fixes, testing edge cases, and ensuring a smooth user experience.

---

## 🎯 My QA Philosophy

> **Quality is my craft.
> Reliability is my goal.**

I believe Quality Assurance is more than finding bugs.

Good QA means understanding:

* What the product is supposed to do
* How real users will interact with it
* What can go wrong
* Where edge cases exist
* How different users may behave
* Whether the experience is consistent and intuitive
* Whether the product is ready for real-world usage

My goal is to help teams identify problems early and deliver software users can trust.

## 🔍 Testing Mindset

My testing approach is based on understanding the complete user journey.

```text
Requirements
     ↓
Understand User Flow
     ↓
Identify Test Scenarios
     ↓
Design Test Cases
     ↓
Execute Tests
     ↓
Find & Reproduce Defects
     ↓
Report Bugs
     ↓
Verify Fixes
     ↓
Regression Testing
     ↓
Final Quality Validation
```

I don't limit testing to the **happy path**.

I also explore:

* Negative scenarios
* Edge cases
* Unexpected user behavior
* Invalid inputs
* Boundary conditions
* Navigation issues
* UI inconsistencies
* Responsive issues
* Performance-related user experience problems
* Real-world usage patterns
