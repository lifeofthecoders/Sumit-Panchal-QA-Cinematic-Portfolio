**## ⚙️ Getting Started**



**### Prerequisites**



-   ****Node.js**** --- Use a current supported Node.js release compatible

    with the installed Vite version.

-   ****npm**** --- Included with Node.js.

-   ****Git**** --- Required to clone and publish the repository.



**### 1. Clone the repository**



``` bash

git clone https\://github.com/lifeofthecoders/Sumit-Panchal-QA-Cinematic-Portfolio.git

cd Sumit-Panchal-QA-Cinematic-Portfolio

```



**### 2. Install dependencies**



``` bash

npm install

```



**### 3. Start the development server**



``` bash

npm run dev

```



Open the local development URL:



``` text

http\://localhost:5173/

```



**### 4. Build the production version**



``` bash

npm run build

```



The production-ready static website is generated in the `dist/`

directory.



**### 5. Preview the production build**



``` bash

npm run preview

```

**## 🚀 Deployment**



The project is configured as a static Vite application and uses the

repository subpath as its production base path.



**### GitHub Pages**



The Vite configuration sets the base path to:



``` text

/Sumit-Panchal-QA-Cinematic-Portfolio/

```



To publish the portfolio:



1.  Push the latest source code to the repository's `main` branch.

2.  Confirm that GitHub Pages is enabled for the repository.

3.  If using GitHub Actions, configure the workflow to install

    dependencies, run `npm run build`, and publish the `dist/`

    directory.

4.  If using the configured `gh-pages` script, run:



``` bash

npm run deploy

```



5.  Open the live portfolio and verify the hero media, navigation,

    project cards, experience timeline, resume asset, and contact links.



****Live portfolio:****



<https\://lifeofthecoders.github.io/Sumit-Panchal-QA-Cinematic-Portfolio/>



**### Vercel**



The project can also be deployed to Vercel:



1.  Import the GitHub repository into Vercel.

2.  Select the Vite framework preset.

3.  Set the build command to `npm run build`.

4.  Set the output directory to `dist`.

5.  Deploy and verify the generated production URL.



For a root-domain Vercel deployment, review the Vite `base` setting

because the current configuration is set for the GitHub Pages repository

subpath.
